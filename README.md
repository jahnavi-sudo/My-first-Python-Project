# Sentiment Analyzer 🐍💬

A Python-based Sentiment Analyzer built to classify text input into *Positive, **Negative, or **Neutral* sentiment. This is my first hands-on Python project exploring core programming concepts and Natural Language Processing (NLP) basics.

## ✨ Features
- Analyzes user-provided sentences or text blocks
- Detects and classifies sentiment polarity (Positive, Negative, Neutral)
- Clean, beginner-friendly Python structure

## 🛠️ Technologies Used
- *Language:* Python 3
- *Concepts:* String manipulation, conditional logic, functions, and basic NLP
